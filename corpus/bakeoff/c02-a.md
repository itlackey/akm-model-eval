# Article Curation Pipeline Location

## Overview
The article curation pipeline is live at `$BUNDLE_ROOT/skills/article-curator/` (skill+script) with workflow `$BUNDLE_ROOT/workflows/curate-to-wiki.md` and daily task `$BUNDLE_ROOT/tasks/curate-agent-learning.yml`.

## Configuration

## Validation Status
Validated 2030-05-23: in 60s the pipeline fetched 50 articles from 5 sources (HN, Semantic Research, OpenAlex, ArXiv AI, MIT Tech Review), selected 9 via LLM rubric (39 paywall-skipped, 2 other).

## Adding New Topics
To add new topics:
1. Drop a new `<topic>.json` in `config/curation/`.
2. Update the task: `akm tasks add <id> --schedule '...' --prompt '...'` or copy the existing task.

## Troubleshooting & Common Issues
If the pipeline fails to fetch articles, check:
- Network connectivity to external sources (HN API, Semantic Research).
- Rate limit headers in responses from OpenAlex/ArXiv.
- LLM context window limits if rubric selection returns fewer than expected items.
- Ensure `config/curation/<name>.json` contains valid JSON syntax and required keys.
