When running `akm lint`, the `stale-path` issue flags files containing absolute filesystem paths that do not exist on the current machine. This commonly occurs in:

1. **Session-derived memories** (`memories/*.derived.md`): These often reference session logs stored in `(agent-runtime-state)

2. **Knowledge files** (`knowledge/*.md`): These frequently contain absolute paths to source code repositories (e.g., data-platform-sv routes, agent-portal components) or container mounts. Fix: Replace absolute paths with relative references, generic descriptions (e.g., "data-platform-sv routes"), or home-relative paths (`~/.config`, `~/.akm`).

3. **Reference lists**: Files listing source files, specs, and helpers often contain full absolute paths. Fix: Remove the path prefix entirely, keeping only the file name or a generic description of the component.

**Strategy**: Never delete entire files. Apply minimal, surgical edits to remove or replace just the stale path references while preserving the semantic content and intent of the memory/knowledge.
