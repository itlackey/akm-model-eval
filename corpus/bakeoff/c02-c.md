# Article Curation Pipeline

This asset documents the live article curation pipeline used to ingest, filter, and index external sources into the knowledge base.

## When to use

Use this asset when you need to:
- Understand how new articles are discovered and filtered daily.
- Add new topics or adjust filtering criteria.
- Troubleshoot ingestion failures or verify source connectivity.
- Locate the configuration files for customizing the workflow.

## Overview

The pipeline is live at `$BUNDLE_ROOT/skills/article-curator/` (skill+script) and integrates with the daily workflow defined in `$BUNDLE_ROOT/workflows/curate-to-wiki.md`. It runs automatically via a scheduled task configured in `$BUNDLE_ROOT/tasks/curate-agent-learning.yml`.

## Architecture

The system consists of three main components:

1. **Skill & Script**: Located at `$BUNDLE_ROOT/skills/article-curator/`, containing the core logic for fetching and processing articles.
2. **Workflow Definition**: Defined in `$BUNDLE_ROOT/workflows/curate-to-wiki.md`, orchestrating the ingestion steps.
3. **Task Scheduler**: Configured in `$BUNDLE_ROOT/tasks/curate-agent-learning.yml` to run daily at 12:15.

## Configuration

Configuration files are stored at `$BUNDLE_ROOT/config/curation/<name>.json`. Each file may include an optional `wiki` field to specify target wiki sections or metadata mappings.

### Adding New Topics

To add a new topic:
1. Drop a new `<topic>.json` file into `config/curation/`.
2. Update the task definition in `akm tasks` by adding `--schedule '...' --prompt '...'` or copying the existing task configuration.
