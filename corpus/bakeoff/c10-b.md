# Zero-Dependency Authored Skills Pattern

This asset documents the architectural decision to build specific automation skills (`skills/social-media/twitter`, `skills/social-media/instagram`, `skills/email-automation`) with **zero external dependencies**, relying solely on Node.js native modules.

## When to use
Use this pattern when deploying scripts to constrained environments (CI/CD, cron jobs) where adding `npm install` steps or managing package versions introduces friction or security risk. It is the preferred approach for lightweight utilities that do not require complex framework abstractions.

## Implementation Details
All scripts in these directories utilize only Node.js built-in capabilities:
- `node:fs` for file I/O operations.
- `node:crypto` for OAuth signing (Twitter) or hashing logic.
- Native `fetch` (available in modern Node.js) for HTTP requests.

This contrasts with the `skills/social-media/bluesky` skill, which uses Bun and requires `@atproto/api` and `@atproto/xrpc` dependencies.

## Benefit Analysis
This design ensures:
- **Easy deployment**: No dependency resolution overhead; runs anywhere Node.js is installed.
- **Reduced attack surface**: Fewer third-party packages mean fewer potential vulnerabilities.
- **Faster startup times**: Avoids the initialization cost of loading external libraries.

**Key Files:** `skills/social-media/twitter/package.json`, `skills/email-automation/package.json` (both show empty `dependencies`).
