# DocumentRenderer Independent Rendering Model

DocumentRenderer renders markdown files independently by concatenating rendered HTML in a loop (`index.ts`). While the markdown-it parser state (e.g., `chapterOpen`, `pageOpen` flags) resets per file, the rendered HTML divs persist in the output buffer.

## The Bug: Unclosed Scope at EOF

If a plugin opens a wrapper div but fails to close it at the file's End-Of-File (EOF), that unclosed tag becomes a silent ancestor for all subsequent files. This breaks the assumption of independent rendering.

## Impact

1. **CSS Leakage**: Rules scoped to `.page.X` or `.chapter.X` may match content from unrelated files if wrappers leaked.
2. **Paged.js Inheritance**: Paged.js clones the accumulated DOM; leaked nesting corrupts page layout.
3. **Plugin Requirement**: Any plugin emitting wrapper tokens MUST ensure they are closed at EOF.

## Verification Checklist

- [ ] Verify all markdown-it plugins close wrapper divs at EOF.
- [ ] Check for unclosed `<div>` tags in the concatenated output.
- [ ] Ensure CSS selectors do not rely on implicit DOM structure across files.
