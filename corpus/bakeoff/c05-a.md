- The akm meta-review prompt set lives at `docs/reviews/akm-meta-review/` in the akm repo: a `README.md` index plus 15 self-contained review prompt files (`01-goal-orientation.md` … `15-maintenance-loop.md`) and a `findings/` output dir.

Each prompt adapts one section of an external researcher's "10 Prompts to Run When Catalog Comes Back" (`wiki:articles/raw/blog-prompts-to-run-when-catalog-comes-back`) into a meta-review of akm's own subsystems. Every prompt ends with `parallel-review` (multi-agent orchestration opt-in; drop it to run solo) and writes its report to `findings/NN-slug.md`.

Run one prompt per fresh session. Run **01 (goal-orientation)** and **05 (metrics-and-evals)** FIRST — they establish the goal and the success metric that every other prompt depends on. The reusable methodology behind the set is `knowledge:example-91c68fdb`.
