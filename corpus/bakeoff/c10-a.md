A key architectural decision for the `skills/social-media/twitter`, `skills/social-media/instagram`, and `skills/email-automation` directories is **zero external dependencies**.

### Implementation
All scripts use:
- `node:fs` for file I/O
- `node:crypto` for OAuth signing (Twitter) or hashing
- Native `fetch` for HTTP requests
- No `npm install` required beyond Node.js runtime

This contrasts with the `skills/social-media/bluesky` skill, which uses Bun and requires `@atproto/api` and `@atproto/xrpc` dependencies.

### Benefit
This design ensures:
- Easy deployment to any environment (CI/CD, cron jobs) without dependency resolution overhead.
- Reduced attack surface.
- Faster startup times.
