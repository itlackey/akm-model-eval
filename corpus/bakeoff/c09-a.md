akm project — how to run tests. Use 'bun run test' or 'bun run test:unit' for the unit suite (both now exclude tests/integration via --path-ignore-patterns=tests/integration). Use 'bun run test:integration' for integration (tests/integration + tests/commands + tests/workflows). 'bun run check' = lint + tsc --noEmit + test:unit + test:integration (the pre-push gate). CRITICAL: never run bare 'bun test ./tests' over the whole tree in ONE parallel pool — unit and integration tests share process-level env/singletons (AKM_STASH_DIR, config/output-mode singletons) and pollute each other under --parallel, producing spurious failures (e.g. cli-errors 'search without stash dir', the in-process harness singleton-leak test). CI deliberately splits them into separate passes; test:unit and test:integration are the supported entry points. bunfig.toml [test] preloads tests/_preload.ts (sandboxes HOME/XDG/AKM env, cwd, fetch) and sets timeout=30000.
